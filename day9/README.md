# Day 9 – Python Object-Oriented Programming (OOP)

## Programs Covered

- Bank Account
- Constructor
- Methods
- Student Class
- Student Project

## Concepts Learned

- Classes and Objects
- Constructors using `__init__()`
- Instance Variables
- Instance Methods
- Creating and Using Objects
- Implementing OOP in Python

## Objective

To understand the fundamentals of Object-Oriented Programming in Python and learn how classes, objects, constructors, and methods help organize and reuse code.

## Learning Outcome

After completing these programs, I can create classes, initialize objects using constructors, define methods, and implement basic object-oriented programs in Python.
