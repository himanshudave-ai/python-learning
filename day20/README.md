## Concepts Learned

- Loading and inspecting student datasets using Pandas
- Calculating average, maximum and minimum marks
- Subject-wise performance analysis
- Finding overall and subject-wise toppers
- Student ranking and percentage calculation
- Applying functions to DataFrame columns
- Data visualization using Matplotlib
- Creating bar charts and pie charts
- Building an integrated student performance dashboard

## Libraries Used

- Pandas
- Matplotlib

## Project Objective

To develop a practical student performance analysis system using Python, Pandas and Matplotlib. The project calculates student results, identifies toppers, analyses subject-wise performance and generates visual reports.
