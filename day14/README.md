# Day 14 – Python Modules and Utility Programs

## Programs Covered

- `program1_math_module.py` – Performs mathematical operations using the math module.
- `program2_random_module.py` – Uses the random module for random operations.
- `program3_datetime.py` – Works with date and time using the datetime module.
- `calculator.py` – Performs calculator operations.
- `program4_main.py` – Main program for the calculator utility.
- `program5_os_module.py` – Demonstrates functions from the os module.
- `program6_sys_module.py` – Demonstrates functions from the sys module.
- `program7_counter.py` – Implements counting-related operations.
- `program8_utility_toolkit.py` – Combines utility functions in a toolkit.

## Concepts Learned

- Importing and using Python modules.
- Using built-in modules such as math, random, datetime, os, and sys.
- Organizing code into separate files.
- Creating reusable utility programs.
